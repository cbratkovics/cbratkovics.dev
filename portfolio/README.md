# cbratkovics.dev

Next.js, TypeScript, and Tailwind CSS source for [cbratkovics.dev](https://cbratkovics.dev).
Site content lives in `data/projects.ts`, `config/site.ts`, and the components under `components/`.
See the repository root `README.md` for the site copy.

```bash
npm install
npm run dev     # local server at http://localhost:3000
npm run lint
npm run build
```

Deployed on Vercel.
